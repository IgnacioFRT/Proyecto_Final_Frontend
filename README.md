Descripción del Proyecto
El objetivo principal es transformar un análisis estático de datos desarrollado originalmente en Google Colab en una herramienta de producción interactiva y accesible. El sistema permite realizar un Análisis Exploratorio de Datos (EDA) y visualizar métricas críticas en tiempo real para la toma de decisiones.

Dashboard en vivo: https://ems-utn-v2.streamlit.app/

Estado del proyecto: activo.

Tecnologías Utilizadas
Este proyecto utiliza un stack basado en Python y herramientas modernas de ciencia de datos:

Lenguaje: Python 3.x.

Framework de Visualización: Streamlit para el despliegue del dashboard.

Análisis de Datos: Scikit-learn, Plotly y herramientas de procesamiento EDA.

Base de Datos: InfluxDB Cloud para la gestión de series temporales de energía.

Infraestructura: Despliegue continuo en Streamlit Cloud mediante integración con GitHub.
